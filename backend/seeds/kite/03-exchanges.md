# Exchanges

We offer **one free exchange per order**, most commonly for a different size
in the same style.

## How exchanges work

Request the exchange from your order page and choose the replacement size or
colour. We dispatch the new item as soon as the original is scanned into the
return network — you do not need to wait for it to reach the warehouse.

If the replacement item is a different price, the difference is charged or
refunded accordingly.

## Limits

- One free exchange per order. Subsequent exchanges are treated as a return
  followed by a new purchase.
- The replacement must be the same product in a different size or colour. To
  swap for a different style, return the original and place a new order.
- Sale items cannot be exchanged.
- Exchanges must be requested within the same 30-day window as returns.

## Availability

If the size you want sells out before your exchange is processed, we convert
it to a refund automatically and email you. You are not placed on a waitlist
unless you ask.
